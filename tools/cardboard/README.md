# Картонная модель — генератор раскроя и инструкции

Скрипты, которыми сделаны файлы в [`cardboard/`](../../cardboard). Нужен Python 3 и `pip install numpy matplotlib shapely`.

```bash
cd tools/cardboard
python cb_sheets.py ../../cardboard                    # raskroy_A4.pdf, raskroy_A3.pdf, laser_svg/
python cb_manual.py ../../cardboard/instrukciya.pdf    # инструкция по сборке
```

| Файл | Что делает |
|---|---|
| `cb_geom.py` | Все детали: профили, шипы, прорези, отверстия под шпажки, позы лап |
| `cb_sheets.py` | Раскладка деталей по листам 1:1 (A4 с разрезом больших деталей, A3, SVG) |
| `cb_render.py` | Простой z-buffer рендер для картинок инструкции |
| `cb_manual.py` | Пошаговая инструкция со взрыв-схемами |

Толщина картона и диаметр шпажки — в начале `cb_geom.py` (`T = 3.0`, `PIN_D = 4.0`). Для картона 4–5 мм поменяй `T` и перезапусти оба скрипта — прорези и размеры пересчитаются.

Профили корпуса и лап упрощены по силуэтам STL; положение лап по ширине (y) — по настоящим деталям KDY0523 (`3d-viewer/stl/kdy`): бедро 77–112 мм, голень 83–103 мм, ось бедра 94 мм. Расстояния между осями суставов — как в `spot_micro.urdf` (186 мм между осями плеч, бедро 107.5 мм, голень 130 мм). Шайбы заполняют зазоры между пластинами, длины шпажек считаются от ширины (`cb_geom.py`: `KNEE_GAPS`, `HIP_GAPS`, `AXLE`, `KNEE_PIN_MM`).
