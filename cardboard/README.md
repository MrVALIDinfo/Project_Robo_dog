# Картонный макет 1:1

Собака из картона в натуральную величину, примерно 32 × 23 × 28 см. Лапы двигаются в бедре и колене.

| Файл | Что это |
|---|---|
| `instrukciya.pdf` | Инструкция по сборке |
| `raskroy_A4.pdf` | Шаблоны на 9 листах A4 |
| `raskroy_A3.pdf` | Шаблоны на 6 листах A3 |
| `laser_svg/` | Файлы для лазерной резки |

Печатать в масштабе 100 % и проверить линейкой отрезок 100 мм внизу листа. Картон — гофрированный, 3 мм.

Для картона другой толщины шаблоны можно пересчитать: [`tools/cardboard`](../tools/cardboard).
