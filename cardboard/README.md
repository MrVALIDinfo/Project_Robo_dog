# Робособака из картона (макет 1:1)

Картонная модель Spot Micro в натуральную величину (≈ 32 × 23 × 28 см): корпус на шипах, 4 лапы, суставы на шпажках — лапы двигаются в бедре и колене. Профили и положение лап по ширине — по настоящим деталям KDY0523 для печати (бедро y 77–112 мм, голень 83–103 мм, ось бедра y = 94 мм). Плечо приклеено к борту: третий сустав (отвод лапы вбок) в картоне не делается.

| Файл | Что это |
|---|---|
| `instrukciya.pdf` | Пошаговая инструкция по сборке (11 шагов, взрыв-схемы, список деталей) |
| `raskroy_A4.pdf` | Шаблоны для вырезания 1:1, 9 листов A4 (большие детали — из двух половинок) |
| `raskroy_A3.pdf` | То же на 6 листах A3, все детали целиком |
| `laser_svg/` | Листы A3 в SVG для лазерной резки (красное — рез, синее — подписи) |

Печатать в масштабе **100%**, проверить шкалу 100 мм внизу листа. Картон **3 мм**. Коды деталей: `ПЛ`/`ПП`/`ЗЛ`/`ЗП` — передняя/задняя левая/правая лапа, `К` — корпус; `П` — плечо, `Б` — бедро, `Г` — голень, `Ш` — шайба. Сторона с надписью — наружу.

Перегенерировать под другую толщину картона — [`tools/cardboard`](../tools/cardboard).
