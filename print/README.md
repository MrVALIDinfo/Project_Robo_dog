# Детали для печати

Сверх комплекта Spot Micro (KDY) — только то, что нужно под [список деталей от 23.10.2026](../README.md#проверка-комплектующих-список-от-23102026).

| Файл | Что это | Крепёж |
|---|---|---|
| `cam_mount.stl` | Кронштейн Raspberry Pi Camera v2 в морду. Камера (25 мм) не входит между рёбрами морды (24.5 мм), поэтому кронштейн надевается на передние кромки рёбер С-образными пазами, а камера стоит на клине перед ними и смотрит вперёд с наклоном 10° вниз. Шлейф выходит вниз между рёбрами. | 4× M2×6 + гайки M2 (гайки вдавить в бобышки); к рёбрам — посадка в пазы + капля термоклея |
| `R_cover_alatoo.stl` | Задняя крышка вместо `R_cover` из комплекта KDY: гравировка «K.D.Y» залита, на её месте выпуклая надпись «ALA-TOO» (заглавные 6 мм, выступ 0.8 мм). Отверстия под LCD и выключатель 19×13 мм — штатные. | как у оригинальной крышки |

Печать: PLA/PETG, 0.2 мм, 3 периметра, заполнение 30 %. Файл уже уложен на стол гранью с минимумом нависаний, поддержки не нужны. Пазы под рёбра — с зазором 0.25 мм на сторону; если сидит туго, пройти надфилем.

Размеры сняты с `3d-viewer/stl/frontpart.stl` и `backpart.stl`. Пересобрать (например, поменять наклон камеры `TILT` или текст `TEXT`):

```bash
pip install numpy trimesh manifold3d networkx
python tools/mounts/make_mounts.py
python tools/mounts/make_rear.py      # ещё нужны shapely matplotlib
```
