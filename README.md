- `3d-viewer/` — 3D-модель в браузере: `cd 3d-viewer && ./start.sh`
- `docs/parts_list_final.pdf` — что купить и схема подключения
- `print/` — что печатать
- `cardboard/` — картонный макет 1:1
- `presentations/`, `wokwi/`, `tools/` — презентации, схемы, скрипты

Управление в 3D-модели: WASD — ходьба, C — сесть. Адрес `?explode` открывает разборку на детали.

Покупать по `docs/parts_list_final.pdf`, а не по старому списку от 23.10: он не подходит по аккумулятору, выключателю, удлинителям и крепежу.

Лицензии — в [NOTICE.md](NOTICE.md).
