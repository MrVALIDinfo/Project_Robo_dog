# Project_Robo_dog

Проект робособаки на базе открытого проекта **Spot Micro** ([mike4192/spotMicro](https://github.com/mike4192/spotMicro), рама KDY0523).

## Что в репозитории

| Папка | Что это |
|---|---|
| `presentations/` | Презентации проекта |
| `3d-viewer/` | **3D-модель собаки в браузере**: настоящие STL корпуса и ног, электроника по README проекта (Raspberry Pi, PCA9685, UBEC HKU5, LCD 16×2 I²C, LiPo 2S, 12 серв) с проводами, логотип на спине и надпись ALA-TOO сзади. Ходьба по обратной кинематике. |
| `wokwi/spot-12-servos/` | Упрощённая схема Arduino Mega + 12 серв + 3 кнопки для симулятора [Wokwi](https://wokwi.com) |
| `wokwi/led-button/` | Базовая схема Arduino Uno: LED и кнопка |
| `docs/` | PDF с размерами для печати, схема LED + кнопка, исходный логотип |
| `tools/dimensions-pdf/` | Скрипты, которыми сделан PDF с размерами |
| `cardboard/` | **Макет из картона 1:1**: шаблоны для вырезания (A4, A3, SVG для лазера) и пошаговая инструкция по сборке |
| `tools/cardboard/` | Генератор раскроя и инструкции (можно пересчитать под другую толщину картона) |

## Запуск 3D-модели

```bash
cd 3d-viewer
./start.sh            # или: python3 -m http.server 8765  и открыть http://127.0.0.1:8765/
```

Нужен только Python 3 и браузер с WebGL. Прямое открытие `index.html` двойным кликом не работает: браузер блокирует загрузку моделей.

**Управление:** `W/S` вперёд/назад, `A/D` поворот, `Shift` быстрее, `Ctrl` или `C` — сесть (держать), мышь — камера. В панели справа: позы, ползунок прозрачности, слои, схема подключения, слайдеры 12 суставов. Наведи мышь на деталь или провод, чтобы увидеть название.

## Схема подключения (по README Spot Micro)

- **Серво:** LiPo 2S 4000 мАч (7.4 В) напрямую на клеммник V+/GND платы PCA9685.
- **Логика:** LiPo → UBEC HKU5 5V/5A → Raspberry Pi (pin 2 = 5V, pin 6 = GND), PCA9685 (VCC, GND), LCD (VCC, GND).
- **I²C (bus 1):** Pi pin 3 (GPIO2, SDA) и pin 5 (GPIO3, SCL) → PCA9685 (адрес 0x40) и LCD 16×2 (адрес 0x27). Общая земля.
- **Каналы PCA9685** (номер серво − 1): RF 1–3, RB 4–6, LB 7–9, LF 10–12 (колено, бедро, плечо).

## Что в модели приблизительно

- Raspberry Pi и PCA9685 — реальные CAD-модели, но Pi — модель **4B** (в проекте Pi 3B, плата 85×56 мм та же, порты другие).
- Серво PDI-HV5523MG, UBEC HKU5, LCD и LiPo — габаритные модели, не CAD.
- Места установки деталей и точки подключения проводов на платах приблизительные.
